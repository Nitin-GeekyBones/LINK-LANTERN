Features

Three ways to check

  • Site checkA single page or a whole website, results streamed to your screen. No account needed.
  • Multi checkUp to 20 sites in one batch, combined report by email. Free account.
  • Auto checkScheduled daily, weekly or monthly scans with emailed and online reports. Paid plans.

What gets detected

  • Error statuses: 404 Not Found, 410 Gone, 403 Forbidden, 500 Internal Server Error and every other 4xx/5xx answer.
  • Unreachable servers: unknown hosts, refused or reset connections, timeouts, TLS certificate failures.
  • Redirect problems: loops, chains longer than 10 hops, redirects with no target, and redirects that end in an error. Each hop is listed.
  • Malformed URLs, such as those containing backslashes.

Where links are found

For every problem the report shows the page it was found on and how it appears there: the clickable text of an anchor, or the element and attribute it came from (for example <img src>). These attributes are scanned:

  • a href
  • area href
  • applet codebase
  • audio src
  • blockquote cite
  • body background
  • button formaction
  • command icon
  • del cite
  • embed src
  • form action (GET)
  • frame src
  • frame longdesc
  • head profile
  • html manifest
  • iframe src
  • iframe longdesc
  • img src
  • img srcset
  • img longdesc
  • input src
  • input formaction
  • ins cite
  • link href
  • meta refresh
  • object classid
  • object codebase
  • object data
  • q cite
  • script src
  • source src
  • source srcset
  • track src
  • video poster
  • video src

Plus every url() and @import inside same-site stylesheets, <style> blocks and inline style attributes. A <base href> is honoured when resolving relative links.

Respectful crawling

  • robots.txt honoured for every host, including Crawl-delay.
  • At most two simultaneous requests per host, with a pause between requests.
  • Automatic slow-down and retry after 429 or 503 answers, honouring Retry-After.
  • Light HEAD requests for anything that doesn't need to be read, falling back to GET only when a server refuses HEAD.
  • Firm limits on depth, page count and link count for every scan.
