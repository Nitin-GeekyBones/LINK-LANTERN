Status & error codes

A link is reported as broken when its server answers with an error status, or when no proper answer arrives at all. Here's what each result in a report means.

Results without an HTTP status

These come from LinkLantern itself when a request couldn't complete normally.

{{customCodes}}

HTTP status codes

Any 2xx answer is a working link. 3xx answers are redirects: LinkLantern follows them (up to 10) and reports the final result along with each hop. 4xx and 5xx answers are broken links.

{{httpCodes}}
